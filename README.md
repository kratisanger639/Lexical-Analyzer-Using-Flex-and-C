# Lexical Analyzer Using Flex and C

## Aim
To implement a lexical analyzer using Flex and C.

## Description
This program identifies tokens in a given input, including:
- Keywords
- Identifiers
- Numbers
- Operators
- Special symbols

## Requirements
- Flex
- GCC Compiler

## Program Execution

### Step 1: Install Flex
```bash
sudo apt-get install -y flex gcc
